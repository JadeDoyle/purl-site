# User guide

How to use Purl. Plain language, no code, no assumptions about
programming or technical background.

This is the written companion to the in-app help (empty states,
first-run tour, tooltips). Read here if you want to sit down and
learn; everything inside the app gives you the same answers in the
moment you need them.

> Note: if you find anything that seems off, or if you have any questions, please send us feedback through the app, or by e-mail [contact@purl.no](mailto:contact@purl.no).

## Start here

- [**Getting started**](./getting-started.md): install, the four
  tabs at a glance, adding your first yarn and your first pattern
  and your first project.

## The everyday loop

- [**Yarn stash**](./yarn-stash.md): adding yarn, colours, dye
  lots, multi-colour yarns, fibre composition, weighing yarn as
  you use it.
- [**Patterns**](./patterns.md): importing a PDF pattern,
  writing your own, sharing patterns with friends.
- [**Projects**](./projects.md): starting a project from a
  pattern, picking yarn from your stash, the project gallery,
  marking finished.
- [**PDF tools**](./pdf-tools.md): row tracker, counters, the
  ruler, drawings, sticky notes + bookmarks, clearing
  annotations.

## Powerful extras

- [**Barcode templates**](./barcode-templates.md): scanning

- [**Calculator**](./calculator.md): gauge swatch,
