Start a project

A project is the thing you are making. It ties a pattern and your yarn together, and keeps track of how far you have come.

  1. Tap Projects, then tap New project.

  2. Type a Name for it.

  3. Tap Choose a pattern and pick one. Add yarn the same way, with Add yarn from your stash.

  4. Scroll down and tap Create project.
